## Setup

- PHP 
- MySQL
- [Composer](https://getcomposer.org/)
- [IssuesPHP Framework](https://github.com/issuesphp/issuesphp)



## Installation

-  Clone Project

```bash
$ git clone https://github.com/issuesphp/docs.git
``` 

```bash
$ composer install
```

```bash
$ php issues.php
```

-  Run Local Server

```bash
$ http://localhost/docs/
```

-  Active mod_rewrite apache

```bash
$ sudo a2enmod rewrite
```
